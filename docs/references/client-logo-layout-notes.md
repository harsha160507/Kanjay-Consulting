# Kanjay website: client-logo decision

User-confirmed direction, 29 October 2026.

## Required when building the website

- Add a cream client-logo section using `#FAF8F3` as the working background.
- Keep this section light/cream in dark mode as well. The surrounding website may follow the dark theme.
- Balance the apparent sizes of the visible artwork, rather than giving all image files the same dimensions. Preserve proportions and use `object-fit: contain`.
- Give WOYC a dark backing because its lettering is white. Preserve all client brand colours and intentional white artwork.
- Use the cleaned logo assets supplied in `kanjay-logos-cleaned.zip`. The cream section is to be added during the website build; it is not baked into the transparent images.
- Prefer the lossless WebP copies, with PNG copies available. The `cleaned-native` folder retains the cleaned artwork at source resolution.
- Do not enlarge small images beyond their useful resolution. Low-resolution source details cannot be recovered by background cleanup. Request original SVGs or higher-resolution artwork when available, especially for Balmer, Kaavian, Golden Works and Hadron.
- The file `UNIDENTIFIED-BLACK-GOLD-MARK` came from a screenshot filename. Confirm its company name before publishing and providing alternative text.
- This package does not verify client relationships or publication approval. Use the project's existing approval requirements.
