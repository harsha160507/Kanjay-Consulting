# Design revision Phase 3 — acceptance test

1 November 2026. Tested application commit **610daf1027e8b73aa1488982cea64c74e8fa8e26** on the existing revision branch / draft PR #11. This update adds test evidence, a verification script and this report only. Application code and synced references were not changed. No merge or deployment.

## Method and acceptance criteria

The owner's eight criteria below are the acceptance contract. PASS means the stated behaviour was actually observed or asserted against the current build; source inspection is explicitly distinguished from runtime testing. NOT TESTED is an outstanding check, not an inferred pass. Browser: ChatGPT in-app browser. Layout sizes: 375, 768 and 1440 CSS pixels, light and dark routes. These are desktop-browser viewport tests, not physical phone/touch tests.

Rebuilt the current application: **34 HTML pages**, sitemap, nine inline-script CSP hashes. `verify-services.mjs`, `verify-revision3.mjs` and the new `verify-revision3-test.mjs` passed. No new performance or screen-reader test was requested/performed in this run; the previous report's limitations remain.

The static test uses an enforced HTTP **`script-src 'none'`** CSP on the same built files at local port 4338, not a hidden fallback forced by CSS or a DOM mutation. The browser-wide JavaScript preference itself was not changed. The build's ordinary local preview remains on port 4337. Evidence: [script-blocking-method.json](references/revision-3-test/script-blocking-method.json).
